a tracker expenses using python and CLI 

in order to run the application, 

1. open the terminal
2. to add items into the list you must enter the file name and then the command
3. to add an item write "add", then the command, for category is "--c" or "--category", for description enter "--d" or "--description", for amount enter "--a" or "--amount"
4. example adding items to the list type: python main.py add --c lunch --d comidas --a 12.00  

to show items, type: python main.py show
